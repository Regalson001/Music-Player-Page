# Music Player Page 🎵🎶

A responsive HTML web page featuring a custom audio player built as part of my frontend software development course.

## 🚀 Features
* **HTML5 Audio Elements:** Implements semantic `<audio>` tags to embed sound directly into the document.
* **Playback Controls:** Utilizes the `controls` boolean attribute to give users full playback management (play, pause, volume, and seeking).
* **Continuous Playback:** Features the `loop` attribute to automatically restart tracks upon completion.
* **Curated Tracklist:** Showcases tracks by artist Quincy Larson, including:
  * *Can't Stay Down*
  * *Cruising for a Musing*
  * *Scratching the Surface*
